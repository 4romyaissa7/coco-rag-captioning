# COCO RAG Captioning

## Project Overview
This project explores Retrieval-Augmented Generation (RAG) techniques for image captioning using the COCO dataset.

## Phase 1
Phase 1 focuses on dataset exploration, preprocessing, metadata preparation, embeddings, retrieval indexing, and quality-control audits.

## Dataset
The project uses a selected subset of COCO images and their reference captions.

## Repository Contents
- `phase1_notebook.ipynb`: Main project notebook.
- `train_image_ids.json`, `validation_image_ids.json`, `test_image_ids.json`: Image split identifiers.
- `metadata.json`: Dataset metadata.
- `dataset_stats.json`: Dataset statistics.
- `audit_report.json`, `qc_report.json`: Audit and quality-control reports.
- `figures/`: Project visualizations.

## Notes
Large dataset files and generated artifacts may be stored separately from this repository.
